# بطاقتي — نظام بطاقات المتربصين

تطبيق ويب RTL لإدارة بطاقات متربصي **المعهد الوطني المتخصص في التكوين المهني حساني عبد الكريم**.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

ثم افتح الرابط الذي يظهر في الطرفية. لبناء نسخة إنتاجية:

```bash
pnpm build
```

## التخزين دون خادم قاعدة بيانات

- لا يحتاج التطبيق إلى MySQL أو API أو حساب خارجي.
- تُحفظ البيانات العاملة محلياً في متصفح الجهاز عبر `localStorage`.
- يوجد ملف بداية مرفق في `data/trainees.json`.
- من صفحة **استيراد البيانات** يمكن استعادة هذا الملف أو أي نسخة JSON لاحقاً.
- استخدم **تصدير JSON** لإنشاء نسخة احتياطية قابلة للنقل إلى حاسوب آخر.

> ملاحظة تقنية: لا يسمح المتصفح لتطبيق ويب ثابت بالكتابة تلقائياً إلى ملف داخل مجلد المشروع. لذلك يستخدم التطبيق تخزيناً محلياً آمناً داخل المتصفح مع استيراد/تصدير JSON، وهو ما يحقق التشغيل دون خادم وقابلية نقل البيانات.

## الوظائف

- سجل المتربصين: إضافة، تعديل، حذف، بحث، إضافة صورة شخصية.
- استيراد دفعي من Excel (`.xlsx` / `.xls`) باستخدام عمود واحد للاسم واللقب (مثل `Ali MOHAMMED`) مع قالب XLS جاهز للتنزيل.
- بطاقة CR80 بنسبة قياسية، بعناوين قابلة للتعديل.
- خيار إظهار أو إخفاء الصورة الشخصية من البطاقة من صفحة تصميم البطاقة.
- علم الجزائر + علم النيجر وشعار وزارة التكوين والتعليم المهنيين.
- نسختان عربية وفرنسية للبطاقة.
- QR Code يحتوي على رقم التسجيل والاسم الكامل ورقم جواز السفر.
- تصميم بخلفية متموجة وتدرج وزخارف زليج وخطوط هلال ونجمة خافتة.
- طباعة شبكة 3×3 في ورقة A4 مع خيار **حفظ بتنسيق PDF** من نافذة الطباعة.
